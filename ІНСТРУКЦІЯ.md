# Квіз «Перші клієнти з TikTok» — запуск

## 1. Що замінити — тільки файл `config.js`
- `PIXEL_ID`: ID твого пікселя Meta.
- `STUDENTS` (93), `COUNTRIES` (11), `SLOTS_PER_WEEK` (6) — уже вписані. `CALL_FORMAT` / `CALL_LENGTH` — формат і тривалість розбору.
- **Відео**: поклади в папку `video` файли `1.mp4`, `2.mp4`, `3.mp4` — вони підтягнуться самі (обкладинка береться з відео). Підписи під ними — в `REVIEWS`.
- **Фото**: поклади в папку `photo` файл `me.jpg` (квадрат). За бажанням — `og.jpg` 1200×630 для прев'ю посилання.
- `SCRIPTS`: посилання на 3 сценарії для кожної ніші. `TG_CHANNEL`: твій канал.
- `BOOK_TIMES` / `BOOK_WEEKDAYS`: коли ти береш дзвінки (час за Варшавою).

## 2. Telegram-бот для заявок
1. Створи бота в @BotFather і скопіюй токен.
2. Напиши своєму боту будь-що. Потім відкрий `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, там буде `"chat":{"id":...}`. Це твій chat_id.
3. У Vercel відкрий Project → Settings → Environment Variables і додай `TG_BOT_TOKEN` та `TG_CHAT_ID`. Після цього зроби Redeploy.

Токен зберігається на сервері (`api/lead.js`), на сторінці його не видно.

## 3. Деплой
Залий папку в GitHub і підключи її до Vercel. Нічого збирати не треба: це звичайний HTML плюс одна серверна функція.

## 4. Події пікселя
| Подія | Коли | Для чого |
|---|---|---|
| PageView | відкрили квіз | — |
| QuizStart (custom) | натиснули першу кнопку | видно, чи працює перший екран |
| QuizQualified (custom) | у 3-му питанні вибрали «наставник» або «частинами» (далі — екран «Складаю твій план…») | аудиторія для ретаргету |
| QuizFree (custom) | у 3-му питанні вибрали «сам(а)» | **виключити** з аудиторій |
| BookOpen (custom) | відкрили екран запису | видно, на якому кроці відвалюються |
| **Lead** + **Schedule** | заповнили форму | **оптимізація кампанії на Lead** |
| ReviewPlay (custom) | дивились відео-відгук | — |

Lead спрацьовує **тільки** після форми, а до форми доходять лише ті, хто готовий платити. Тому Meta вчиться шукати платоспроможних людей.

## 5. Гарантія: умови для договору / сторінки оплати
У квізі вона написана коротко. Повні умови оголошуй на дзвінку і прописуй у договорі.

> Повертаю 100% оплати, якщо за 30 днів навчання ти виконав(-ла) **всі** умови і не отримав(-ла) жодної заявки:
> 1. Опублікував(-ла) 30 відео за 30 днів за сценаріями з курсу.
> 2. Здав(-ла) всі домашні завдання в чаті в терміни.
> 3. Був(-ла) на всіх групових зустрічах або подивився(-лась) записи протягом 48 годин.
> 4. Відповідав(-ла) на коментарі та директ за скриптом з курсу.
> 5. Подав(-ла) запит протягом 7 днів після 30-го дня з посиланнями на всі відео.

Умови чесні, і їх легко перевірити. Хто виконує всі п'ять, той майже завжди отримує заявки, тому запитів на повернення буде дуже мало. Перед тим як писати умови в договір, проконсультуйся з юристом щодо законодавства країни, де ти працюєш.

## 6. Перевірити локально
Відкрий термінал у цій папці і виконай `python3 -m http.server 8000`, потім відкрий http://localhost:8000. Форма локально не відправить заявку (функція `api/lead.js` працює тільки на Vercel).
